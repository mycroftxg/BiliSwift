# 0.3.1 实现与验证状态

日期：2026-11-08（0.3.0 首版当天修复 4 项）。环境：Apple Silicon / macOS 27.2 / Xcode 27.2。最低 macOS 26。

## 0.3.4 首页滚动与头图

- Hero 轮播去掉嵌套横向 ScrollView，改为点击圆点/横向拖拽/7 秒自动切换，鼠标在头图上时纵向滚动不再被吞。
- 头图标题与简介宽度按窗口收缩，最小窗口下不再被裁切；头图高度随窗口高度自适应。
- 横向栏目去掉负 padding，避免内容宽度溢出导致的横向错位。

## 0.3.3 播放器窗口装饰

- 沉浸播放时隐藏红绿灯、工具栏、标题与侧栏开关，返回按钮独占左上角；退出播放后恢复（已实机截图验证）。

## 0.3.2 图片管线

- 封面走 `@720w.webp`、头图 `@1440w`、头像 `@96w_96h_1c.webp`，单图从 150–330 KB 降到 3–30 KB。
- 共享 `RemoteImageStore`：256 MB 内存缓存、512 MB 磁盘缓存、同 URL 并发去重、ImageIO 后台降采样。
- 全部 `AsyncImage` 已替换；列表滚动回看直接命中缓存。

## 0.3.1 修复

- 侧栏按钮不再重复；沉浸播放时隐藏窗口工具栏与标题，保留系统红绿灯。
- UP 主主页的视频不再因为合集 `season_id` 被当成 PGC 剧集（此前进入剧集页报 -404）。
- 高级画质/音轨切换失败时保留当前播放并提示，不再中断；优先回到上一组可播放片源。
- UP 视频卡片补全时长，播放量不再被误标为“哔哩哔哩”。

## 具体限制和仍需验收

1. **UP 投稿访问**：当前网络的未登录请求出现服务端 -352／HTTP 412。资料读取可使用公开 card 接口回退；投稿等受限栏目显示验证入口。风控测试只验证了受限状态处理，不等于已经验证全部 UP 投稿可读。需要用户在官方页面自行完成验证后重试。
2. **会员高级输出**：HDR、杜比视界、Hi-Res、杜比全景声分别识别和选择，但真实屏幕／音频输出尚未验收。系统就绪和源格式标签不能证明实际高级输出。DRM 媒体目前明确提示不支持。
3. **直播聊天**：原生直播视频可播放，实时聊天弹幕尚未接入。
4. **写操作**：需要用户验证点赞、三连、投币、收藏、关注及发布行为。三连会产生真实投币／收藏等账号操作，不做自动化测试。
5. **全面 QA**：所有分区逐一实机浏览、全部 UP 栏目与权限、VoiceOver、不同显示器和音频设备、长期能耗与网络异常尚未全面完成。
6. **发行**：仅本机临时签名，尚未 Developer ID、公证或公开发行。

弹幕时间线以 60fps 为目标，实际帧率仍受设备、系统和并行负载影响，不宣称已测得持续 60fps。
